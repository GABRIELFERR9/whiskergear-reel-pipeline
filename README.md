# whiskergear-reel-pipeline

Montagem automática de Reels (Python + FFmpeg) a partir de footage, motion graphics e logo.

Script que monta um Reel vertical do WhiskerGear a partir de footage, motion graphics e logo, com FFmpeg.

## Uso
```bash
python montar_reel.py
```
Requer Python 3 e FFmpeg. Coloque os vídeos de footage em `footage/` (não versionados).
